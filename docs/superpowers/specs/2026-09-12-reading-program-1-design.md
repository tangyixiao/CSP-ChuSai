# 阅读程序（1）重构设计

## 目标

在不改变原题 16--20 的题型、题干风格、输出效果、考察知识和答案的前提下，重构阅读程序（1）。程序仍然完成原来的字符串边界回退与长度累加，但题面代码不再直接出现 `pi`、`prefix`、`KMP` 等明显提示。

## 设计

采用中等复杂度的指针实现：

- 用动态 `char* text` 保存输入字符串。
- 用动态 `int* jump` 保存每个位置对应的回退信息。
- 通过 `getChar`、`goBack`、`findNext` 三个短函数拆开字符访问、回退和继续匹配。
- 用 `*(text + pos)` 与 `*(jump + pos)` 展示指针运算，但不引入类、模板或逐字符动态申请，避免把难点转移到高级 C++ 或内存管理。
- 在程序末尾使用 `delete[]` 释放两段动态内存。

## 题目与答案约束

- 保留原题 16--20 的判断题、输出计算题、`while` 改 `if` 对比题、复杂度题和原选项。
- 重新计算并同步代码行号；不手工沿用旧行号。
- 解析中可以解释实际考察的前缀函数回退，但题面代码和题面文字不直接暴露算法名称。
- KMP 图表改成普通的“长度回退链”表达，不使用 `pi` 变量名。
- 不改阅读程序（2）、阅读程序（3）和完善程序的算法、题型与答案；线段树继续使用“区间乘加线段树”名称。

## 验收标准

1. 新代码与旧代码对原有样例和 Q16--20 的计算结果一致。
2. 新代码中不存在 `pi`、`prefix`、`KMP`、`failure`、`next` 这些提示性标识。
3. 题面、答案、考点矩阵的程序行号一致。
4. 两份 XeLaTeX PDF 均二次编译通过，日志无错误、未定义引用、溢出和缺字警告。
5. 渲染检查代码页、阅读程序 1 题目页、答案图表页和线段树页，确认无裁切、重叠或不可读内容。
6. Git 提交只包含合并版题面、答案、PDF、考点矩阵及本设计/计划文件，不包含 `c5p-s-2026-revised*.tex`。
